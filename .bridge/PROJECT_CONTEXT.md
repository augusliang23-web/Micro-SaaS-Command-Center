## Verified local capabilities

- The loopback state API persists valid local state in `data/app-state.json`.
- The loopback GitHub API provides read-only repository and pull-request
  signals.
- The V0.4 Command Center consumer can request a local Codex App Server
  handoff. Its proposal phase is a read-only repository inspection and relies
  on a server-side local allowlist.

These local capabilities are not, by themselves, operational authority for
approval, merge, deployment, release, billing, or provider execution.

## Non-authoritative dashboard state

Project gates, review labels, execution status, environment status, activity,
fixture data, browser-memory data, user-entered text, and AI-generated text
remain non-authoritative unless an immutable external evidence reference proves
the claimed fact. In particular, visible default text must not be interpreted
as an established Bridge discussion, human approval, or completed execution.
