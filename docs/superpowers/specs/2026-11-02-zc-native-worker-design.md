# Native worker pilot — Issue #108

Owner authorized native subscription verification and one bounded PM task, with at most two fix rounds, no paid API/overages, settings, secrets, cloud/data or release actions. Reuse task #107/#95 and PR #96; extend PR #106. This is one foreground local pilot, not an arbitrary-task scheduler.

## Product contract
Safari shows the fixed recorded task and a separately enabled native-job button. A click reserves one stable job, validates GitHub/task/source identity, invokes a verified Plus-native Luna Low patch producer, applies its bounded CSS proposal to an isolated local branch, runs the existing offline browser regression, compares the final source tree with PR #96 and links that existing Draft PR. The UI reports real events/results and keeps owner acceptance pending. Roles and existing V1 remain unchanged.

The coding model produces a typed patch; it does not receive GitHub credentials or authority to run commands/write files. Host policy validates the exact approved CSS delta before applying it. This is a real native model contribution and real isolated source/test execution, not an offline mock. A matching PR is reused transparently; no duplicate task/PR or synthetic claim of a newly created PR.

## Approach and safety
Use the existing desktop-bundled App Server and native permission profiles, verified on 7 harmless positive/negative tests. PATH CLI is older; no install/update or global settings change. Per-invocation MCP/app/web/remote features are disabled. Account must be chatgpt, subscription windows available, exact Luna/Low in native catalog. A model/tool mismatch, unknown tool event, permission request or provider uncertainty holds. UserMessage/reasoning/agentMessage are messages, not tools. The earlier fixed probe's broad item counter is not zero-tool proof and is not repeated.

Task/grant/job/event contracts remain provider-neutral. Native thread ids stay inside the adapter and are excluded from task/job/GitHub evidence. Server-side zc.authorization/v1 is bound to Issue #108, task id, repository/base and capabilities. A browser cannot grant itself execution authority. Native response schemas and provider prompts are adapter details.

One private append-only local reservation blocks replays/restarts, plus bounded authenticated GitHub comment reconciliation. Uncertain writes never retry. GitHub evidence is the durable shared record; local journal is single-worker crash evidence, not a distributed claim or defense against arbitrary malicious same-UID host processes. Mac settings race HOLD remains unchanged. No daemon or automation.

## Validation / non-goals
Offline boundary/state/patch/RPC tests and exact-head CI. Independent actual-diff review before live job, then real Safari dispatch, source/test/tree evidence. PM app data and deployed UI/UAT are not loaded. No release approval. If the native environment cannot enforce the profile, HOLD; do not fall back to broad access. No extra mock-only components.
