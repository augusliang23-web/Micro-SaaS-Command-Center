- **`src/components/FeatureDeliveryMatrix.tsx`** — targeted rewrite of the highest jargon-density prose blocks: the top banner intro, the "Feature Ingestion Hub" drawer header, the AI-PRD-sync tab's description and loading state, the paste-AI tab's instruction text, and the GitHub-issues tab's intro line. Left the data-table column headers and field labels (Stage/Prod status, Feature Flag Key, etc.) as-is — those are structural labels for a real data concept the table already displays consistently elsewhere in the app, not throwaway jargon prose.

Flagged this to the owner via `AskUserQuestion` rather than silently fixing it; he approved fixing it. While fixing it, found a second, larger layer of the same problem in the same file — the `/api/bridge/chatgpt-advice` route's success/fallback JSON responses also carried "ChatGPT Bridge Engine", "ChatGPT Bridge (Local Fallback Policy)", "### ChatGPT Architecture Evaluation", and "Actionable Directive for Codex (Terra Tier)" (all rendered in the `ChatGPTBridgeModal` UI), plus two route comments. Flagged this larger discovery separately, distinguishing it from the real system prompts sent to the actual OpenAI/Gemini APIs (`systemPrompt`/`userPrompt`/`contentToExtract` at lines ~102, ~111, ~229 of `server.ts`) — those are functional payloads to a live external API, not display text, and CLAUDE.md's "provider behavior" protection applies squarely to them. The owner explicitly chose to fix only the display/fallback strings and leave the real prompts untouched. Changed: the two route comments (`// Live Architecture Advice Endpoint for...`, `// Live AI Auto-Extraction of Features from...`), the Gemini-success-path `provider` label, the local-fallback-path `provider` label and its `analysisMarkdown` heading and "Codex (Terra Tier)" directive line, and the one mock-candidate `description` string.
